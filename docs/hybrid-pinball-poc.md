# Hybrid Pinball PoC

현재 기본 브랜치 `master`의 `7cbf3fb`를 바탕으로 만든 개념검증(Proof of Concept, PoC)입니다. 기획 출처는 [핀볼 발전안 정리](chatgpt-conversation://6adf3613-16b4-83ec-a8b5-a20e51c73dc3)입니다. 그 대화에서 미정이었던 아케이드는 추천안인 **월드별 점수 도전**으로 구현했습니다.

## 플레이

앱에서 모드, 열린 월드, 난이도, 스테이지를 선택하고 시작합니다. 게임판 왼쪽·오른쪽을 누르면 해당 플리퍼가 움직입니다. 오른쪽 아래 발사대를 아래로 당겼다 놓으면 발사합니다. 키보드는 A/D 또는 좌우 방향키, Space 또는 아래 방향키로 조작합니다. W 또는 위 방향키는 테이블 밀기이며 새 모드에서는 1초에 한 번 사용할 수 있습니다. R은 현재 판 재시작입니다.

일시정지 버튼, Android 뒤로 가기, 앱의 백그라운드 전환은 현재 판을 멈춥니다. 다시 화면으로 돌아와도 계속 버튼을 눌러야 진행됩니다. 일시정지 전에 잡고 있던 터치는 취소되며 일시정지 중 키보드 입력도 게임을 바꾸지 않습니다.

## 스테이지와 기록

| 스테이지 | 목표 |
| --- | --- |
| 1-1 달빛의 입구 | 100,000점 |
| 1-2 꽃이 피는 밤 | 위쪽 보석 범퍼 세 개를 각각 충전한 뒤 상단 게이트 통과 |
| 1-3 월식의 수호자 | 방어막을 열고 츠키비나 격파 |
| 2-1 불빛의 거리 | 150,000점 |
| 2-2 이어지는 전류 | 공을 잃기 전에 12콤보 |
| 2-3 네온 감시자 | 드론 보스 격파 |
| 3-1 가라앉은 빛 | 200,000점 |
| 3-2 네 개의 봉인 | 하단 타깃 네 개를 각각 맞힌 뒤 상단 게이트 통과 |
| 3-3 심연의 파수꾼 | 심해 보스 격파 |

각 스테이지는 공과 점수를 새로 시작합니다. 클리어하면 다음 스테이지가 열립니다. 공 손실 0개는 별 3개, 1개는 별 2개, 2개 이상은 별 1개입니다. 잠금 해제는 난이도 사이에 공유하고, 별점과 최고 점수는 난이도별로 저장합니다. 실패하면 현재 스테이지를 재도전합니다.

아케이드는 열린 월드 하나에서 유한한 공으로 점수를 쌓습니다. 보스 격파마다 50,000점을 받고 격파 연출 뒤 새 보스가 등장합니다. 이때 점수와 남은 공은 유지됩니다. 최고 점수와 최대 콤보는 월드·난이도별로 분리합니다. 점수는 보스 격파와 게임 종료 때 기록하며, 진행 중인 판 자체를 저장·복구하지는 않습니다.

기존 물리 타격 점수의 20배를 적용하고, 보스 피해를 포함한 10콤보마다 10,000점을 추가합니다. 기존 독립 실행용 `MonPinballGame()`은 원래 규칙을 유지하며, 앱의 두 새 모드는 `RunConfiguration`을 통해 같은 엔진을 사용합니다.

## 난이도와 보스

아래 수치는 달의 정원 기준입니다. 후반 월드는 [별도 계수](world-visual-development.md)를 적용합니다.

| 설정 | EASY | NORMAL | HARD |
| --- | --- | --- | --- |
| 시작 공 | 5 | 3 | 3 |
| 방어막 해제 타격 | 2 | 3 | 4 |
| 약점 노출 | 8초 | 5초 | 3초 |
| 공격 주기 | 12초 | 9초 | 7초 |
| 발사 후 볼 세이브 | 12초 | 7초 | 3초 |

좌우 위쪽 보석이나 하단 타깃을 맞히면 방어막이 충전됩니다. 방어막 중 피해는 없고, 노출 시간에는 기존 몸통·약점 판정을 사용합니다. 공격은 각 주기의 마지막 1.8초에 실행됩니다. 체력 60% 이하에서는 공격 중 왼쪽 레인이 실제 충돌 장벽으로 닫히고, 30% 이하에서는 공격 주기가 20% 짧아집니다. 오른쪽 경로는 열려 있습니다. 공의 중력·질량·발사 속도·플리퍼 물리는 난이도에 따라 바뀌지 않습니다. 새 모드는 느린 렌더링 프레임을 최대 1/60초의 물리 계산으로 나누어 발사 에너지를 보존합니다. 긴 멈춤 직후 한 프레임에서 따라잡는 시뮬레이션은 0.25초로 제한합니다.

볼 세이브는 각 유료 공의 첫 발사에 한 번 제공됩니다. 시간 안에 잃으면 공을 차감하지 않고 재발사를 기다립니다. 세이브 재발사는 새 세이브 시간을 주지 않습니다. 공 손실 시 콤보는 초기화되고, 보스 체력과 일반 미션의 충전은 유지됩니다.

## 구현 범위와 검증

2026-10-29부터 네온·심해는 위쪽 범퍼 위치와 실제 충돌 장치도 다릅니다. 네온은 회전 전극과 축전기, 심해는 움직이는 수문과 봉인석을 사용합니다. 벽·발사대·플리퍼는 공유합니다. 두 새 보스는 원본 생성 그림과 Canvas 움직임·공격 전조를 결합합니다. 상세 변경은 [월드 시각 개선](world-visual-development.md)을 참고하세요. 꽃잎·그림의 장식 부위는 충돌하지 않고, 실제 보스 방해는 예고된 레인 장벽입니다. 오디오, 마라톤 모드, 진행 중인 판 복구는 포함하지 않습니다.

기록은 `shared_preferences`의 로컬 저장소에 보관합니다. 저장 실패 시 메모리의 기록을 유지하고 안내를 표시하며, 후속 저장으로 복구할 수 있습니다. 앱 삭제·기기 변경 시의 기록 이전은 제공하지 않습니다.

검증 명령은 `flutter analyze`, `flutter test --no-pub`, `JAVA_HOME="/Applications/Android Studio.app/Contents/jbr/Contents/Home" flutter build apk --debug --no-pub`입니다. 전체 테스트는 기존 물리·렌더링 비교와 함께 고유 타깃, 게이트, 방어막·레인 충돌, 모드 전환, 저장 복원·실패, 일시정지 입력 취소를 다룹니다. 실제 실행 결과와 실단말 관찰 범위는 구현 커밋 본문에 기록합니다.
